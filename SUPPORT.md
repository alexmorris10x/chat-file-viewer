# Support

Use [GitHub Issues](https://github.com/alexmorris10x/chat-file-viewer/issues) for reproducible bugs and focused feature requests. Include the iOS version, device or simulator, file type, minimal sample input when safe, expected result, and actual result.

This project is maintained on a best-effort basis with no guaranteed response time. Do not post private chat exports, credentials, personal files, or vulnerability details in public issues. Report security problems through [SECURITY.md](SECURITY.md).
